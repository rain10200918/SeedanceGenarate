# Agent 公开资料搜索（第一阶段）

目标：缺资料 → `web-search` → 保存 `WEB_RESEARCH` → 脚本引用来源 → 沿原计划自动继续。

## 启用

给后端进程配置环境变量 `TAVILY_API_KEY`，然后重启后端。IDEA 运行配置使用“环境变量”栏，不是“有效配置文件”；Docker Compose 从部署环境/Secret注入同名变量。不要把真实值提交到代码、数据库、前端环境变量或日志。

没有配置时，搜索能力不向 Planner 暴露。配置存在不等于已通过远端认证；错误密钥/配额限制会保留进度并给出安全暂停。生产部署前请验证实际搜索账户额度。搜索可能消耗 Tavily 额度；本阶段没有新增用户钱包扣费规则。

本阶段只实现 Tavily Adapter，但 Skill 依赖 Provider-neutral `SearchProvider`，不是 Tavily 的响应结构。官方协议：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)。使用 basic 文字搜索，关闭正文、答案、图片返回，不自动放宽检索限制，也不抓取结果网页。

## 如何使用

新建 Agent 对话，例如：“请制作天津武清气象局宣传片脚本，先自行搜索公开资料，优先气象局和政府官网，不编造机构事实。”

如果 Agent 提议创作计划，仍沿用现有“采用计划”操作；采用后资料步骤完成会自动进入下一次决策，不需手工输入“继续”。已有活动计划不被静默插入新步骤。脚本后续若生成视频，仍走原费用确认，不把搜索授权当作媒体授权。

研究卡显示检索来源、URL、摘要和检索时间；“引用此版本”沿原 `source: {artifactId, version}` 使用准确版本。来源资料独立保存，脚本通过来源链保留引用，而不是再次调用搜索。

## 资料边界

- `WEB_RESEARCH` 在本阶段代表可复用的公开检索资料，不是完整深度研究。
- 来源摘要和摘录标记 `SEARCH_RESULT`，没有正文核验，不输出伪造 `VERIFIED`。
- URL、域名或搜索排名不证明事实准确；历史报道不能冒充最新情况。
- `publisher`、`publishedAt` 未可靠取得时为空，不由模型猜日期或官方等级。
- 上游网页内容是非可信资料，不得改变审批、权限和 Runtime 指令。
- 不下载外部图片/视频，不访问登录站点，不处理商业使用授权。
- 只发送公开短关键词。明显凭据/联系方式拦截不是完整DLP；不能把内部文件、私密信息当搜索词。

## 执行边界

每次最多5条来源；同一计划的总请求预算3次（含重试），无计划时按会话epoch计数，跨Turn不会重置。瞬时错误有界延迟重试，成功调用不会因恢复而再搜索。结果不足保留资料并请求补充，不为追求完成编造事实。

搜索运行在原持久化Job链里；不是Planner私自联网，也不是SSE连接维持任务。LangChain4j只产生决策，搜索不会进入钱包或媒体Task提交链。具体测试与已验证范围见 `.my-loop/DELIVERY-web-search-p1.md`。
